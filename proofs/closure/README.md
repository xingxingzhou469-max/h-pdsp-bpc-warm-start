# 42 个单车实例的独立上界复算

以随包路线为下界，验证器读取原始有向弧、服务时间、库存、车容及人口，逐例排除任何更高目标。Python 用标准库核验输入和证人，搜索部分用本机支持 C++17 和 128 位整数的 Clang 或 GCC 编译。可从仓库根目录重放单例。

```bash
python3 proofs/closure/verify.py instances/blind-09.json solutions/blind-09.json
```

`--build-dir` 可以指定复用的编译缓存目录，`--seconds` 可以调整单例搜索时限。超时、程序失败或未覆盖全部分支时，验证器以失败结束。逐例分数、输入与路线指纹、分支覆盖计数见 [results.json](results.json)。

| --- | ---: | --- |

## 分数和固定次序

令全体人口为 $T$，实际访问机构的人口之和为 $P$，送量为 $F$。记机构人口和送量为 $p_i,y_i$，未访机构取 $y_i=0$。把原公平目标乘以 $T$，可写成 $N=\sum_{i,j}\min(p_i y_j,p_j y_i)$。因此 $N\le PF$。对选定的反向后缀，其在正向路线之前的机构只能使用后缀外的库存。用 $P_s$ 表示后缀人口、$S$ 表示后缀外可用库存，把上述双重和按一个下标是否在后缀内拆开，还可得 $N\le P_sF+PS$。

在固定次序上任选一组机构 $A$。只向这组机构送货时，遇供点尽量装满、在选中机构卸空就得到最大可送量 $r(A)$。每步的累计送量和累计送量加现有库存都支配任一可行取送决策。对任意分组顺序，把组内、组间的各项最小值按此顺序取一个线性上界，能把 $N$ 限制在各组送量的加权和以内。系数为本组人口加两倍的后续组人口，依次递减。按组序累加的送量均不超过相应的 $r(A)$，故可用各组累计秩之差替代各组送量，得到上界。程序选边际送量与人口之比最小的组来收紧该上界。同一连续配送段可并成一组，其外部载货条件只依赖段内的总送量。

## 反向游走表

对反向前缀，$F$ 可取固定完整路线的最大总送量。原始库存和车容是整数，所以此数为整数。反向遍历时在每个机构将车装满，在每个供点尽量卸至该点的供给上限，可以计算总送量上界。对尚可到达的站，用原有向弧及服务时间重建整数游走表。简单路线全部包含在游走松弛中。给每个站的供给、人口加权计分，减去非负访问价格，最终加回所有尚可访问的站价。简单路线每站至多计一次，因此所得量约束每种合法补全的 $aF+bP$。结合 $F,P$ 的各自上限和 $4abFP\le(aF+bP)^2$ 可以缩小乘积上界。单独限制供点子集的最短旅行加服务，以及机构服务可覆盖的人口，进一步排除时间不足的补全。上界在完整路线覆盖结束后才可与证人配对。

blind-09 另附两组整数访问价格，分别使用供给与人口权重 $(1607,1000)$、$(2200,1000)$。价格由反向游走提出，复算时逐项检查其范围并从原弧重新生成两张表。验证器关闭 32 个末站根及全部 138 个两站子任务，展开 732,696 个前缀，对 1,884 条完整路线检查固定次序上界。最高分子为 1,588,500，全体人口为 2,353。把检验门槛下调一个分子单位时，搜索找回随包证人路线并拒绝该门槛。[整数价格](blind-09-prices.json)

访问集合程序沿用历史原生独立复核器，反向程序沿用 Random 独立复证工作中的 donor 和 wide-window 实现，blind-05 沿用独立时间树证书。此处扩展了 24 站支持、blind-09 的外部整数价格校验，并直接从随包规范 JSON 重建搜索输入。每次运行只读取这里的验证材料和指定的实例、路线。
