# 多车 H-PDSP 数学模型、严格上界证明与学术边界

本文简要记录多车人道主义取送问题（Multi-Vehicle Humanitarian Pickup and Distribution Problem, H-PDSP）的精确数学口径、`v2.1` 产出的四类可独立重放严格上界证书，以及正式报告中的评价边界。

---

## 1. 问题定义与精确口径

给定有向图 $G=(V,A)$，顶点集 $V=\{0\}\cup S \cup D$，其中 $0$ 为中心仓库，$S$ 为供点集合（每站有正供给 $s_i>0$，人口 $p_i=0$），$D$ 为受助机构集合（每站有正人口 $p_i>0$，供给 $s_i=0$），且 $S \cap D = \varnothing$。每条弧 $(i,j)$ 有非负有向通行时间 $t_{ij}$，每站有非负服务时间 $\tau_i$。车队包含 $K$ 辆同质车辆，每车载重上限为 $C$，单车路由总耗时（含服务与返仓）上限为 $T$。

**可行车队**由至多 $K$ 条起止于仓库 $0$ 的简单有向路线 $R_1,\dots,R_m$（$m \le K$，允许闲置车辆）及沿途逐站取送量构成，须满足：

1. **站点唯一性**：全车队每个非仓站点至多访问一次。
2. **时限约束**：每条路线 $R_r=(v_1,\dots,v_\ell)$ 的总用时 $t_{0,v_1} + \sum_{a=1}^{\ell-1} t_{v_a,v_{a+1}} + t_{v_\ell,0} + \sum_{a=1}^{\ell} \tau_{v_a} \le T$。
3. **载重与供给守恒**：出仓空载；经供点 $i\in S$ 取货 $0 \le q_i \le s_i$，经机构 $j\in D$ 卸货 $0 \le q_j$；沿途任意时刻车载量始终位于 $[0, C]$（允许非零余载回仓）。

**公平性最大化目标**（Eisenhandler & Tzur, 2019）：记全体机构总人口 $P = \sum_{j\in D} p_j$（含未访问机构），记机构 $j\in D$ 实际收到的配送量为 $d_j \ge 0$（未访问则 $d_j=0$），目标最大化：

$$
Z(d) = \sum_{j \in D} d_j \;-\; \frac{1}{P} \sum_{\substack{i, j \in D \\ i < j}} \bigl| p_j d_i - p_i d_j \bigr|
$$

等价地，将全部受助机构按人均分配率 $r_j = d_j / p_j$ 降序排列，若第 $a$ 个机构之前累计人口为 $H_a$，则

$$
Z(d) = \frac{1}{P} \sum_{j \in D} r_j \cdot p_j (p_j + 2 H_j)
$$

给定固定路线集 $\{R_1,\dots,R_m\}$ 后，每条路线内部的最优取送量可由精确有理数水填法（加权主分划 / Robin Hood 算法）在多项式时间内求得，且跨车合并后的全局目标仍保持精确最优。本仓库所有下界 $L$ 均以 Python `fractions.Fraction` 零容差复算上述全部约束与目标。

## 2. 四类可独立重放的严格上界证书（`v2.1`）

`verify_multi.py` 在纯 Python 标准库（`python3 -B -S`）下无需 HiGHS/NumPy/C++ 即可从原始输入独立重建并验证以下四类严格上界证书，保证覆盖原问题的所有可行车队：

### (1) `ng-product-v1`（二维 $(Q, P)$ 支撑多边形 + 精确 ng-route / 2-cycle 动态规划）
- 由固定分配公平目标的凸性上界可知，对任意可行车队，其总配送量 $Q = \sum_{j\in D} d_j \le Q_{\max}$ 与受助总人口 $P_{\text{vis}} = \sum_{j:d_j>0} p_j \le P$ 满足解析包络 $Z \le \Phi(Q, P_{\text{vis}})$。
- 对任意线性组合权重 $(\alpha, \beta, \pi, \lambda)$，通过单车受限动态规划（`per_vehicle` 或 `pooled` 模式，支持 `cycle2`、有序载重投影和 `ng`-neighborhood 禁环）精确求得单车在整数化时间/载重网格上的有效最大值，构成二维 $(Q, P_{\text{vis}})$ 空间中的有效线性支撑不等式。
- 验证器从原始输入独立重放每条支撑不等式的精确整数 DP（或校验其有效对偶不等式），再在多边形交集上用精确有理数求 $\max \Phi(Q, P_{\text{vis}})$，得到覆盖全部可行解的严格上界。

### (2) `exact-fleet-route-screen-v3`（阈值引导的精确路线/车队全筛）
- 给定父级有效多边形上界（或无父界时直接全枚举）与目标阈值 $\theta$：仅保留有可能参与构成目标超过 $\theta$ 的单车有效候选路线，随后在跨车站点不交约束下对车队组合做精确回溯枚举。
- 若存在超过 $\theta$ 的可行车队，枚举找到其中的全局精确最优解（并附带 `maximizing_witness` 直接闭合并证优）；否则证明任意可行车队得分 $\le \theta$。
- 验证器在纯 Python 中按证书记录的相同阈值与网格重跑精确筛查，逐字段核对转录一致性，并独立验算返回见证。

### (3) `active-supplier-cover-v2`（活跃供点覆盖分治）
- 适用于供点数较少但单供点大供给的场景（典型如多供点 Latet 配置）。把全部可行车队按“实际参与取货的活跃供点集合”划分为若干互斥或覆盖子分支：
  - 活跃车数较少的低活跃度分支；
  - 逐个排除特定供点后的子问题分支；
  - 以及结合带标记供点定价的精确约束。
- 验证器逐叶独立重放各子分支的 `ng-product-v1` 证书，再按精确有理数取所有覆盖分支的全局最大值。

### (4) `visit-branch-v1`（高频站点访问状态分枝）
- 选取 1–3 个对偶价值最高的关键站点作为标记集 $M$，用带标记状态掩码的精确 DP 生成条件支撑，在“各关键站访问次数至多为 1”的精确组合约束下将可行域分解为有限叶子。
- 验证器重放父级多边形和带标记支撑，并在组合叶子上精确聚合得到全局上界。

## 3. 学术评价口径与公开边界

为保证审阅透明，本仓库在全部表格与文档中严格区分以下口径：

1. **严格最优 vs. 严格开放区间 vs. 数值对偶**：
   - 仅当零容差重算的 `L_exact == U_exact` 且 `U` 来自纯标准库可重放严格证书时，标注 `strict_optimal = True`。
   - 当 `L_exact < U_exact` 且 `U` 通过严格证书重放时，报告严格开放区间 `[L, U]` 及相对差距 `(U - L) / L`（均以精确分数判定是否 $\le 5\%$）。
   - Site-MILP（HiGHS）的浮点对偶界仅单列为 `numeric_U`，不作为严格证明参与 5% 认证计数。
2. **单次 60 秒冷启动 vs. 长预算 / 跨硬件结果**：
   - Apple M4 60 秒单线程冷启动（Stage B 96 盲图、Latet 20 配置、Formal 25 基线对照）与 Kaggle CPU 3600 秒 / 10 种子 / 1–2 小时结果分开制表，不混合跨硬件最好值。
3. **当前已知难点与适用边界**：
   - 在 $n=19$（24/24 严格证优）、$n=40$（19/24 $\le 5\%$）、$n=60$（23/24 $\le 5\%$）和真实 Latet（19/20 $\le 5\%$）上，`v2.1` 表现稳健。
   - 在 100 站、低载重/紧时间（如 `lgA-100` 及新盲图 `new-*-01/03`）上，60 秒内严格差距仍在 9%–18% 区间，且在 60 秒纯找解对照中修正版 `MV-LNS` 在 6/25 例上取得了高于 `v2.1`（30 秒找解切片）的可行值。进一步收紧 100 站严格上界与提升多块重启找解效率是后续研究重点。
4. **Latet 原数据与论文表 2**：
   - 20 个 Latet 配置均由 10 份原始工作簿规范化而来（`stage_b_20_latet.csv` 保留原始工作簿 SHA-256 及供给核对）；$K=3$ 为本研究扩展配置，原论文表 2 仅作结构对齐参考。
