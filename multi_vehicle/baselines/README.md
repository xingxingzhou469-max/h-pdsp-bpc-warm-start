# 多车 H-PDSP 论文对照基线说明

本目录包含用于同条件对照的三组论文方法复现代码，均在同一份规范 JSON 输入、相同车队规模 $K$、同一墙钟预算、单线程与种子 7 下运行，并由同一个零容差有理数验算器（`multi_vehicle/engine/common.py:verify_lower`）独立重算每条发布路线的可行性与精确目标。

## 1. 三种基线及与原论文的对应关系

| 模块 | 对照来源 | 实现要点 | 结论口径 |
| --- | --- | --- | --- |
| [`site_milp.py`](site_milp.py) | Eisenhandler & Tzur (*Operations Research*, 2019) §3 & §9 | 三索引站点弧流 + 载重守恒（含回仓余载 `f[k,i,0]`）+ MTZ 去子环 + 全机构配对公平目标；建模前用精确有理数最短路裁剪不可达/超时弧；HiGHS 1.16 单线程，容差 `1e-8`，无项目暖启动。 | 每次回调解码的整数路线由外层精确重配并零容差验算计入 `L`；HiGHS 浮点对偶界仅单列为数值界 `numeric_U`，不混入严格上界。 |
| [`mv_lns.py`](mv_lns.py) | Eisenhandler & Tzur (*OR*, 2019) §§5–6 | 精确有理数 Robin Hood 固定路线配量 + 跨车合并洛伦兹公平计分；6 类站点邻域 + 6 类财富邻域（共 12 算子）、温度 $100000/t$ 模拟退火、每 100 轮及改进后段内有向 2-opt/单站重插。 | 仅输出独立验算的可行下界 `L`；无上界证明。 |
| [`segment.py`](segment.py) | Eisenhandler & Tzur (*Transportation Science*, 2019) §§2–6 及在线附录 A | 在 `mv_lns.py` 基础上周期性调用受限超段序列 MILP（HiGHS）：从当前解与最近 5 个改善车队提取最多 30 个基本段、构造最多 60 个超段（至多串接 4 段且要求内部转货），以当前车队零载重拆分为初始解求解重排。 | 受限池 MILP 的状态只反映当轮 60 列子池，**不是**原问题全局上界；仅产出完整可行解 `L`。 |

## 2. 修正记录：混合角色抽样归一化

在首轮复现审计中发现，旧版 `mv_lns.py` 在涉及“同时涵盖供点与机构”的混合移除/插入动作（`remove_station`、`replace_station`、`insert_station`、`insert_at_wealth_segment`）中，直接把供点供给量 $s_i$ 与机构人口 $p_i$ 在同一权重数组里混抽。当机构人口与供点供给量级差异悬殊（例如 Latet 数据中供给量上万而单机构人口几十）时，移除概率与插入概率会严重向单一角色偏斜。

本发布版已应用角色归一化修正（`_available_role`）：当供点与机构两类角色均可操作时，先以等概率 $1/2$ 选择角色，再在该角色内部按原论文权重抽样；仅存单一角色时在该角色内抽样。25 例正式对照（`multi_vehicle/results/formal_25_baselines.csv`）中的 `mv_lns` 与 `segment` 均使用修正后代码；`cloud_supplementary.csv` 中早期 3600 秒 Kaggle 对照仍为修正前版本，表中已显式标注。

## 3. 与原论文实验环境的差异说明

- **求解器与硬件**：原论文使用 CPLEX 12.6 + Python 2.7，单车 LNS 与超段实验预算最高 3600 秒；本仓库使用开源 HiGHS 1.16 + Python 3.13，在本地 Apple M4 单线程 60 秒下做同条件对照，并在 Kaggle CPU 补充 3600 秒长预算对照。
- **超段复现变体**：原论文作者代码未公开，本仓库 `segment.py` 为适配 60 秒短预算采用 60 列池上限与约 4 秒 LNS / 6 秒 MILP 交替切片，应定位为“受限超段复现变体”，而非作者原始实现的逐轮复刻。
- **Latet 表 2 口径**：TS 2019 表 2 给出 10 份 Latet 数据的双车相对改善百分比与相对作者上界的差距，未公开逐例绝对目标值与上界值；本仓库所有正式结果均以原始工作簿规范化 JSON 下的独立精确分数为准。
